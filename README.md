# 📘 LeetCode Revision Repository

Welcome to my **LeetCode Revision Repository**! 🚀

This repository contains solutions to LeetCode problems that I have solved during my coding journey. The main purpose of this repository is **revision**, so I can quickly review important concepts, algorithms, and problem-solving techniques before interviews, contests, or coding assessments.

## 🎯 Purpose

* 📚 Store solved LeetCode problems in one place.
* 🔄 Regularly update the repository whenever I solve a new problem.
* ⚡ Revise important questions in a short amount of time.
* 🧠 Improve problem-solving skills by revisiting previously solved problems.
* 💼 Prepare efficiently for coding interviews.

## 📂 Repository Structure

Each solution includes:

* Problem Name
* Problem description
* Solution Code


## 🔄 Updates

I continuously update this repository whenever I solve a new LeetCode problem.

**Update Process:**

1. Solve a new problem.
2. Add the solution to this repository.
3. Commit and push the changes.
4. Use this repository for future revision.

## 📈 Goal

The goal is not just to collect solutions but to build a **personal revision guide** that helps me quickly recall algorithms, data structures, and common interview patterns.


## ⭐ Why This Repository?

Instead of searching through hundreds of problems again, I can use this repository as a **quick revision notebook** to review important questions in limited time before interviews or contests.
